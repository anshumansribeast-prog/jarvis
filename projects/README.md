If Semicolon / Cosmos are **not** already at `C:\Users\Anshu\semicolon` and `C:\Users\Anshu\cosmos`, clone them here so the workspace and `python team.py ada` can find them:

```powershell
cd C:\Users\Anshu\anshux\projects
git clone https://github.com/anshumansribeast-prog/semicolon.git
git clone https://github.com/anshumansribeast-prog/cosmos.git
```

Then reopen `anshux.code-workspace`. You can also keep clones as siblings (`..\semicolon`, `..\cosmos`) — `team.py` looks in both places.
